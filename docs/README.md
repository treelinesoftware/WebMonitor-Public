# WebMonitor help

WebMonitor is a self-hosted dashboard for a home or small-office network:
uptime, what every device is, switches and Wi-Fi, traffic, alerts, and OS
updates through a small agent. Everything runs on your own server.

## Install

- [System requirements](requirements.md): hardware, OS, ports and what devices need
- [Install on Rocky Linux](install-rocky.md): the install script, upgrades, backups
- [Install with Docker](install-docker.md): Docker Compose, settings, upgrades, backups
- [Local test copy](local-testing.md): try it, test an upgrade or work on the code on your PC
